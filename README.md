YouTube Clone
This is a simple clone of YouTube, created using only HTML and CSS. It aims to replicate the basic structure and layout of YouTube's homepage, providing a minimalistic, static design for educational purposes.

Features
Homepage Layout: Replicates the YouTube homepage with a video grid layout.

Video Thumbnails: Displays video thumbnails for each video.

Search Bar: Includes a search bar at the top for searching videos (non-functional in this version).

Sidebar Navigation: Mimics the YouTube sidebar with links to different sections.

Responsive Design: Mobile-friendly layout that adjusts to different screen sizes.

Tech Stack
Frontend:

HTML5

CSS3
